# quantum-chemistry-orca

Quantum chemistry calculations with ORCA, mainly to derive force-field parameters for molecular dynamics.

| Project | What it is |
| --- | --- |
| [`resp-charges-pvc-dehp`](resp-charges-pvc-dehp/) | RESP partial charges for DEHP and PVC oligomers (3, 5 and 20 units), used in the PVC/DEHP MD study in [md-projects-gromacs](https://github.com/saichaitanyajagarlapudi2008-droid/md-projects-gromacs) |

## Tools

ORCA · Multiwfn
